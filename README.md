# Sony (sony)

Sony Group Corporation is a Japanese multinational spanning electronics, gaming, entertainment, image sensors, and financial services. Sony's developer-facing surface is anchored by a portfolio of open-source libraries and embedded SDKs maintained at github.com/Sony, including the NNabla deep-learning framework, Sonyflake distributed ID generator, gobreaker circuit breaker, and the Spresense IoT board SDK.

## APIs / Libraries

- **[NNabla](https://github.com/sony/nnabla)** — Sony's Apache 2.0 deep-learning framework.
- **[Sonyflake](https://github.com/sony/sonyflake)** — 63-bit distributed unique ID generator (Go).
- **[gobreaker](https://github.com/sony/gobreaker)** — Circuit-breaker library in Go.
- **[Spresense SDK](https://github.com/sonydevworld/spresense)** — Hexa-core Cortex-M4F IoT board SDK.
